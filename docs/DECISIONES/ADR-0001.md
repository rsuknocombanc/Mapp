# ADR-0001: Arquitectura de arranque
Estado: aprobada para prototipo el 2026-11-16.
Usar HTML estático + MapLibre GL JS, OpenStreetMap/OpenFreeMap, GitHub Actions y Pages. Mantener main estable y usar PR. El paso a React/TypeScript/Vite se evaluará como decisión posterior. No copiar recursos gráficos protegidos de Firewatch; usar sólo inspiración estética.
