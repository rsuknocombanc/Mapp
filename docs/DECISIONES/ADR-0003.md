# ADR-0003 — Hipsometría DEM y geocodificación con Photon
Fecha: 2026-11-16. Estado: IMPLEMENTADO EN PROTOTIPO, APROBACIÓN VISUAL PENDIENTE.
Reemplaza el patrón repetitivo de ADR-0002 para la versión v0.3.1 sin borrar el historial documental.
## Decisión
Aprovechar `color-relief` con expresión `["elevation"]` (MapLibre GL JS >=5.6), sobre tiles DEM Terrarium de Mapterhorn, para pintar colores de elevación por bandas absolutos. Añadir sombreado hillshade leve, conservar fuentes vectoriales OSM/OpenFreeMap para agua, vías y puntos de interés. Eliminar patrones Canvas forestales. Atenuar rellenos de áreas verdes y esconder capas `fill-extrusion`, manteniendo huellas de edificios 2D cuando existan.
Buscar lugares mediante Photon (komoot, datos OSM), con debounce, cancelar solicitudes obsoletas, 5 resultados por búsqueda, sin backend, sin tokens, sin almacenar ubicación GPS del usuario. Usar centro visual del mapa para sesgo geográfico. Se prioriza error recuperable y fallbacks sin bloquear el mapa.
## Alternativas y riesgos
Texturas pictóricas por mosaicos y modelos propios: posponer. Nominatim público: no usar para autocompletado (política de uso). Photon es instancia gratuita para tráfico ligero y no ofrece disponibilidad garantizada. Elevación DEM en 512 px puede generar demora de carga según red; validar Safari real y considerar niveles de zoom o desactivar hillshade si es necesario. UAT obligatorio antes de integrar main.
