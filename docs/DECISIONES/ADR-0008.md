# ADR-0008 — Observabilidad visual sin telemetría externa
Fecha 2026-11-17. Estado: aplicado al prototipo v0.5.1; pendiente validación UAT.
Se añade `#buildStamp` con número de versión incrustado en app.js y en el HTML, nombre de estilo, nivel de zoom y cantidad de sprites generados. Se obtiene el conteo mediante callback `onStats` de `MappForest.install`; no se expone al exterior, no se solicita GPS y no se añade endpoint ni dependencia. Se prefiere un identificador semántico reproducible a consultar GitHub API en cada carga.
Alternativa descartada: mostrar solo v0.5 sin contexto; insuficiente para investigar bosque ausente. No exponer SHA mediante llamada dinámica a API pública.
El conteo ayuda a discriminar si faltan datos forestales/candidatos (0) versus si la capa generó árboles pero son poco visibles (>0); no confirma visibilidad real ni la razón de cada fallo.
Se mantiene pendiente la corrección de fidelidad visual de MAP-0007; esta versión solo añade diagnóstico, no densidad ni paleta.
