# ADR-0002 — Cartografía artística sin perder precisión
Estado: implementado experimentalmente; aceptación visual pendiente.
Fecha: 2026-11-16. Requerimiento MAP-0002.
Decisión: MapLibre GL JS será el compositor geográfico. Polígonos de bosque del tileset vectorial se pintarán con un patrón generado en Canvas (128×128 px, paleta por estilo). Sombreado topográfico DEM con hillshade 2D se añadirá debajo de elementos importantes cuando el servidor de elevación esté disponible. CSS aporta grano superficial a la UI/escena. El Jimny sigue siendo SVG independiente y anclado a coordenadas.
Justificación: preservar coordenadas, zoom, tipos de caminos, ríos y legibilidad del mapa sin ilustrar un mapa ficticio estático.
Alternativas futuras no aprobadas aún: símbolos arbóreos dispersos con semilla por tesela, curvas de nivel de dataset adicional, texturas prerenderizadas regionales, custom shader WebGL.
Prohibición: copiar arte, mapas, logotipos o recursos propietarios de Firewatch.
