# Contexto vigente — Mapp
Fecha: 2026-11-16.
Repositorio: rsuknocombanc/Mapp; rama estable main.
Producto: mapas reales personalizables, optimizado para Safari iPhone.
Tecnología prototipo: HTML + MapLibre GL JS + OpenStreetMap mediante OpenFreeMap; publicación GitHub Pages.
Diseño: off-road vintage inspirado en ilustraciones de mapas de aventura; referencias proporcionadas por el usuario. Diferentes versiones artísticas futuras: manchas verdes texturizadas para bosque, árboles dibujados y vista estrictamente superior.
Ubicación: marcador de vehículo modular tipo Suzuki Jimny naranja, visto desde arriba; GPS bajo permiso del usuario; ubicación inicial de demostración.
Estado: prototipo experimental v0.5.1 en rama feature/bootstrap-vintage-map, PR #1. Mapa plano de papel y masas acuareladas con bosques oliva, agua petróleo, contornos pastel y árboles originales dibujados en Canvas, como símbolos MapLibre georreferenciados y distribuidos determinísticamente sobre cobertura OSM; sin DEM ni 3D. Vías por zoom. Búsqueda Photon, rutas OSRM demo y trazado libre; GPS opcional. Sintaxis y UI simulada validadas localmente, Safari real aún no validado. Inspiración general de mapas de aventura, no recursos propietarios de Firewatch.
Punto de continuidad: comprobar rama/HEAD/PR #1, CI, Pages y UAT Edge/Safari; el UAT visual MAP-0007 sigue abierto por escasez de árboles e insuficiente diferencia de estilos. Evaluar indicador v0.5.1 (tema, zoom y símbolos generados) para aislar causa. No se cambiaron densidad ni paleta. main estable, única rama temporal.
